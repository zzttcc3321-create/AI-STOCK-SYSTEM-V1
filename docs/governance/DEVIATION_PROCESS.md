# 偏差处理流程 DEVIATION_PROCESS V1.0

- STATUS: FROZEN
- VERSION: 1.0
- 适用范围：AI股票系统 V1 所有任务执行过程

## 偏差三类

- **类型1 实现错误**：代码 bug、测试不通过 → 修复后重新走 CODE_REVIEW
- **类型2 设计遗漏**：冻结设计没覆盖到的场景 → 补设计，GPT 确认后继续
- **类型3 违反冻结**：如新增交易接口、改动架构边界 → 立即升级 qi 决策

## 处理流程

1. 发现偏差 → 先冻结现场、保留状态，不急着修
2. 进入 DEVIATION_REVIEW 状态，登记下表字段
3. 分类定级 → 按上表处理
4. 类型1/2 由 GPT 判；类型3 必须 qi 拍板
5. 关闭偏差，TASK_STATUS 留痕

## DEVIATION_REVIEW 必填字段

- Deviation ID / 发现人 / 发现时间 / 影响范围 / 临时措施 / 最终决定 / 关闭时间

## 规则

- 不直接判 BLOCK，先分类再处理
- 偏差关闭前，任务不得进入 DONE
