## 输入与日历

仅从仓库外路径读取 Tushare `candles` 与 `fields`，输出不含 JSON 顶层其他内容。交易日历按上交所公告写入限定窗口的闭市区间；非工作日闭市与工作日节假日闭市不算数据缺失。未被日历解释的缺行只标为“缺少交易日/可能停牌”，不能自行认定停牌。来源：[2023](https://www.sse.com.cn/disclosure/dealinstruc/closed/c/c_20221227_5714459.shtml)、[2024](https://www.sse.com.cn/disclosure/dealinstruc/closed/c/c_20231226_5733941.shtml)、[2025](https://www.sse.com.cn/disclosure/dealinstruc/closed/c/c_20241223_10767110.shtml)、[2026](https://www.sse.com.cn/disclosure/dealinstruc/closed/)。窗口外年份未验证，代码会拒绝使用。

OHLC 必须正价且 `low ≤ open,close ≤ high`；日期不得重复；`pre_close` 必须与上一行收盘衔接，已公告的除息调整例外。`pre_close` 是行情参考价，现金分红用公告的精确每股额。2025-07-03 公告额 0.086 元，前收盘 2.77 元减后为 2.684 元，按行情两位小数成为 2.68 元。没有公告匹配的差异、缺交易日或异常价会阻止因子和基准生成。

## 分红与复权

除息日及每股现金分红（含税）：2024-07-04 0.09 元、2025-07-03 0.086 元、2026-07-06 0.13 元。来源：[吉林高速 2024 实施公告](https://www.jlgsgl.com/storage/2024/ad/572a1b5214d977fbb05a53f44d18a2.pdf)、[2025 实施公告](https://www.jlgsgl.com/storage/2025/e2/886f9b1d17717740e1409e7576514c.pdf)、[2026 实施公告](https://www.jlgsgl.com/storage/2026/d6/62506cafac99e6fdb5122aa109b964.pdf)。基准在除息/发放日将 `持股数 × 公告每股金额` 计入**现金**，不买入更多股。

指标用前向累计现金分红复权序列，版本 `stage1-cash-dividend-v1`：首日因子 `F=1`；非除息日延续；除息日 `F_t = F_{t-1} × C_{t-1}/(C_{t-1} − D_t)`，其中 `C` 是原始收盘价，`D` 是已公告的精确每股现金额。OHLC 同乘当日因子。计算中保留 Decimal 精度，导出的因子表四舍五入至 12 位小数。因此每一历史时点只依赖当日及以前已发生的公司行动，不把未来分红带回开发段。逐日因子表见 [ADJUSTMENT_FACTORS.json](ADJUSTMENT_FACTORS.json)，其哈希只覆盖蜡烛数据，不覆盖源文件中的私有字段。**成交模拟仅用原始未复权报价；因子价不得成交。**

## 费用与仓位

| 项目 | 固定口径 |
| --- | --- |
| 双边佣金 | 每笔成交额 × 0.025%，每边至少 5 元，逐笔人民币分四舍五入 |
| 卖出印花税 | 卖出成交额 × 0.05%，逐笔人民币分四舍五入；买入无印花税 |
| 滑点 | 每股每边：乐观 0 元、基准 0.01 元、压力 0.02 元；买入加价、卖出减价 |
| 清算 | 买入扣成交额和佣金；卖出收成交额减佣金和印花税 |
| 制度 | A 股 T+1，新买入股须下一个交易日才能卖；当天两个方向均禁止回转；现金和股份不得为负 |
| 未回补数量 | 卖出增加、后续买入减少，不能因同日买回而清零 |

持仓账本按买入日期 FIFO 扣除可卖股。除息日开盘交易前可对前一收盘时仍持有的股份一次性入账公告现金分红，按持股总现金额保留到人民币分；重复入账或除息日交易后补记会报错。买入、卖出、拒绝交易都保持资金和仓位状态可验证；对现金不足、可卖股不足或逆时序交易报错。税费模型是任务指定假设，不据样本外行情调整。

## 持有基准与隐私

公开可提交的基准采用**每股**标准化：首个观测日原始收盘价作为窗口起始市值；每日日终权益为 `原始收盘价 + 累计已发现金分红/股`。总收益率为末日权益除首日市值减一；最大回撤是窗口中各日权益相对此前最高权益的最大跌幅。无再投资、无新增交易和清仓动作，因此不加入假想买卖费用。

任务给定的参考股数与历史成本可能涉及真实持仓。按“真实持仓永不进 Git”红线，这些输入及可反推其值的成本收益只允许运行时传参并留在仓库外的本地结果；配置、因子表和 PR 报告均不存储。运行时参考成本 P&L 与窗口新买入持有收益是两个不同问题，不能混为一个数。
