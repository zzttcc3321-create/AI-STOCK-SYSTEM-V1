## 开发段结果与失败原因

- **V1.0（PR #50/#51/#54/#55）**：事前登记的 21 组门槛与滑点组合全部零交易、零已实现做 T 净额，没有可采信的收益改善证据。A-F1 与第一批 2.95 元价位在开发段同日交集为零；随后 D 严格人工锁存长期阻断交易。结构诊断中，收盘至少 2.95 元仅 3 日，A-F1/F2/F3 与该价位交集均为零。零交易的权益与买入持有相同，不是做 T 有效的证据。详见 [开发段报告](STAGE2B_DEV_REPORT.md)、[隔离复验](STAGE2B_R1_ISOLATION_RERUN.md)、[结构诊断](STAGE2B_R1_DIAGNOSTICS_REPORT.md)。
- **V1.1（PR #56 设计、PR #57 验证）**：移除 A-F1 同日要求后，D0 主方案在 0 / 0.01 / 0.02 元每边滑点下仍全部零交易、常规完成率 0%、已实现扣费净额 0、相对含分红持有基准的超额 0%。开发段仅有的 3 个高价日全部处在 D0 锁存期，故放松 A 入口无法形成可执行卖单。预登记的常规完整回补、正净额、完成率和基准档正超额等硬门槛未达，判 `STRATEGY_FAIL`，不以其他方案补分。详见 [V1.1 开发段报告](V1_1_B_DEV_REPORT.md)。
- **D1 只作压力观察**：机械代理解除 D 的 D1-N1/N2 主参数均出现唯一一次完成轮次，性质是亏损的风险回补，不是常规达标回补。按 10,000 单位研究尺度，三档已实现扣费净额为 −288.73 / −338.71 / −388.70 元，超额为 −1.11% / −1.30% / −1.49%；常规完成率仍为 0%。代理解除没有人工授权效力，结果不得并入 D0 正式结论，也不得换算成真实账户损益。

## 双层验收与限制

工程层 **`ENGINEERING_PASS`**：PR #57 的开发段隔离、因果时序、FIFO 股数与现金、费用、状态事件和敞口对账通过；[预登记](V1_1_B_PREREGISTRATION.md)和[报告](V1_1_B_DEV_REPORT.md)的 SHA256 与现行文件一致。PR #57 合并门禁首跑连接中断，记为 `INCONCLUSIVE`；阿七合并核对时取得重跑的 pytest 汇总原文为“1205 passed, 2304 subtests passed in 710.52s”。仓库 [试验登记](EXPERIMENT_LOG.md)既有 V1.1 本地全量记录为 `1205 tests OK`，两者是不同运行记录，不互相冲突。这里不把合并门禁数字冒充为本次重新执行。

策略层 **`STRATEGY_FAIL`**：只按预登记 D0 主方案三档判定。工程通过说明固定实验可运行、可对账，不能推导盈利或解套改善。状态定格 `CLOSED_STRATEGY_FAIL`，`LIVE_STRATEGY_AUTHORIZATION = NO`；不得启用正式门禁、采用 D1 代理解除、临场调参、接券商自动下单或把零交易解释为安全获利。任何后续研究均须另立预登记及授权。

适用范围仅为上述开发段、假设研究仓位和日线次日开盘成交近似。费用按双边佣金万分之 2.5（各边最低 5 元）、卖出印花税 0.05%、每边滑点 0 / 0.01 / 0.02 元和 T+1；交易价用原始未复权价，指标用只依赖当时已知信息的现金分红调整序列。已核验三次除息为 2024-07-04 每股 0.09 元、2025-07-03 每股 0.086 元、2026-07-06 每股 0.13 元；第三次发生在开发段之后，不回填开发段信号。日线模型不证明真实盘口成交，样本外段没有策略验证，亦无真实持仓、税务和执行授权结论。
