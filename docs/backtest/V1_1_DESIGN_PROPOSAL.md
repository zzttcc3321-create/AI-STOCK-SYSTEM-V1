**A7 双层权限。**研究层仅在 V1.1-B 离线模拟回测中，达到预登记风险退出条件时可模拟次日开盘风险回补，并把实际模拟成交损益入账。实际使用层的正式系统仅生成风险提示、建议回补数量和价格估算；由 qi 人工决定是否执行。正式系统不得自动提交真实买单，不得连接券商。研究层的模拟成交不得写成实际使用层已完成交易。

**A7 资金、跳空与待办。**离线模拟按次日开盘价加买入滑点及买入佣金估算可负担数量，向下取至合法交易单位，重算总支出不得超过可用现金；禁止使用未批准外部资金。次日跳空高于卖出价仍按实际模拟成交价计入风险回补亏损及整体策略已实现扣费净收益。买回不足时，剩余股份继续记 `OPEN_UNREBOUGHT` 或 `INVALIDATION_REVIEW` 并保留敞口。现金不足、无合法可买数量、数据异常、C/D 阻断均须形成带原因的明确失败事件，不能伪造已完成回补。已触发的“风险退出待买”持续对应未回补股份；后续重评时即使单日 B/突破条件消失，或第六天已不再满足“恰为第五天”，也不得静默取消。C/D 期间挂起，解除后按仍待处理的股份重发模拟候选；常规回补若先实际完成部分，风险待办随剩余股数减少，直到股数归零才关闭。

同日事件顺序：除息现金按前收盘持股在开盘前入账；前日信号的开盘候选按已知暂停、股数、现金和各自价带规则核验并模拟成交；当日收盘更新状态后，`D/C 暂停 > 风险退出待买 > 常规回补 > 新卖出`，只留一个次日开盘候选。单次风险回补候选只活到该开盘，失败即记录原因；**风险退出待买事项不随候选失效而消失**，下一合格收盘继续处理。不得以次日开盘反改前一日信号。A7 的卖出后交易日计数从成交后下一完整收盘起算。B/C/D 暂停信号和期末未回补均保留审计事件。
