# 给 qi：吉林高速做 T 研究结论

**结论已定：现有方案没有拿出帮助解套的可靠证据，不批准实盘使用。**两轮研究都只在过去的一段数据上做了模拟；软件检查通过，赚钱条件没有通过。研究状态为“策略失败，已关闭”，实盘授权为“否”。合并研究材料只是保存失败证据，不代表可以照方案下单。

## 做了什么，看到什么

研究先把交易费用、分红、交易日和风险暂停规则定清楚，再用 2023-10-09 至 2025-09-30 的 485 个交易日测试吉林高速机动仓做 T。第一次方案规定：价格进入 2.64–3.00 元箱体，还要满足均线走平，才考虑分批卖；遇到趋势转强暂停卖，跌破 2.64 元暂停回补，跌破 2.40/2.30 元进入停摆和失效审查。预先定好的 21 种费用与收益门槛组合，全部没有交易，因此没有证明能多赚一分钱。

第二次方案放宽了“卖出当天必须均线走平”的要求，并预先约定严格的收益和风险考核。结果仍是零交易：开发段仅有 3 个达到第一批卖出价附近的高价日，却都处在必须等待人工处理的风险锁定期。按三档交易滑点测试，正常方案均未完成一轮买回，也没有比一直持有多赚。不能为了得到交易而跳过风险锁定。

研究另外模拟了“假设风险锁定已解除”的情形，只用于看风险，不能当作已获人工批准。这种情形唯一一次买回是亏损的紧急买回；按假设的 10,000 单位研究仓位，三档分别亏 288.73、338.71、388.70 元，比一直持有分别差 1.11%、1.30%、1.49%。这些数不是 qi 真实账户损益，也不能拿来替换正常方案的失败结论。

## 已定的边界

- **不得实盘启用这套规则**，不得把研究软件的通过或 PR 合并理解成策略获批；不得自动向券商提交卖单或买单。风险买回在研究中是模拟，实际决定只能由 qi 人工做。
- 不得私自解除风险锁定、放宽原定收益门槛、从试过的变体里挑一个好看的结果、启用第三或第四批，或用尚未开放的样本外行情改规则。
- 早期研究曾违规解析整份原始文件，包含本应封存的时段；没有计算或报告那段行情。总指挥已于 2026-10-22 作出附限制通过的 R1 裁决，关闭补审；违规事实永久保留。后来改用只读到开发段末尾的方式，不能抹去先前违规。

本次能确认的是：固定方案和账本能被核验，但在已允许的开发段内，**没有做 T 改善解套的证据**。样本外行情继续封存，真实交易不在本研究许可范围内。详细依据见[收官报告](V1_0_V1_1_FINAL_CLOSEOUT.md)和[冻结清单](STRATEGY_RESEARCH_FREEZE_MANIFEST.md)。
