## 证据边界与 V1.1 提案摘要

供是否提出 V1.1 修改案审查的证据：本段 ≥2.95 仅 3 日；A-F1/F2/F3 分别成立 48/98/135 日，但与该价位的交集均为 0；D0/D1-N1/D1-N2 的 D 状态分别为 402/45/53 日，三种场景各 21 档均在漏斗首层为 0。这证明本开发段同日交集缺失，不能证明 A 与价位普遍互斥，也不能外推到封存段。D1 只是代理假设，无法据此验证人工解除的真实结果；零首层使门槛和成交层级没有可识别信息。本报告不选门槛、不提出正式规则修改结论。
