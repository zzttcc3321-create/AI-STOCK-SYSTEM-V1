# 吉林高速 Stage 2A 待决清单

来源优先级：总指挥 2026-10-22 四状态裁决高于 V1.0 送审稿。这里只能核对任务卡转述的原稿价带，**未取得完整原稿时不补造原文**。Q01–Q14 均为规则确认门禁；候选仅供总指挥与 qi 裁决，当前 `rules_v1.json` 对缺口留 `null`、禁止 Stage 2B。数字阈值的最后选定安排在后续开发段比较及样本外验证，不在 Stage 2A 偷选。

## Q01 第三、四批卖出价带与状态 A/B

- **问题/出入：**原稿只记录第一批 2.98–3.03、第二批 3.08–3.12；第三、四批的区间完全缺失。四状态新裁决把 A 上沿设为 3.00，B 在周收 >3.00 且均线/量条件满足时暂停卖出。第一批部分高于 A，第二批全部高于 A。
- **候选：**① 四批都只允许在 A 内，重新划定第一至第四批的箱体内价带，并修订原稿前两档；② 前两档保留为“报价观察区”，超出 A 时暂停执行，第三/四档只在重新进入 A 后按另定箱体内价带执行；③ 保留原稿前两档，但为 B 不成立且价格 >3.00 的情况新增经批准的卖出状态，B 成立时仍暂停；第三/四档随后另定。各案的具体第三/四档端点均须另批，不能从第一/二档外推。
- **影响：**卖出机会、批次顺序、卖飞量、机动仓敞口均会变；不同衔接可能使第二批永远不可执行。
- **拍板：**总指挥定状态和价带，qi 确认无冲突与可执行性。

## Q02 两个回补档位的数量与卖出批次映射

- **问题/缺口：**原稿仅记 2.76–2.82 与 2.62–2.68，两档各回补多少、按哪个已卖批次回补未知。
- **候选：**① 按 FIFO 卖出批次逐股回补，各档上限由已卖未回补量决定；② 两档分别匹配指定卖出批次并固定份额；③ 每档按当时未回补量的比例回补。均受不得净加仓约束。
- **影响：**费用最低额、已实现净额、未回补结局及股息暴露均不同。
- **拍板：**总指挥定数量/顺序，qi 核对账本和费用分摊。

## Q03 B 暂停卖出时的批次及挂单

- **问题/出入：**原稿价带触发卖出，新口径 B 明令“暂停机械卖出”；已触发未成交的批次/挂单未定义。
- **候选：**① 进入 B 立即撤销全部未成交卖单，离开 B 后重新评估；② 暂停订单并保留队列位置，但 B 期间绝不成交，离开后重新校验；③ 只记录观察而不挂订单，退出 B 后重新计算价带。既有部分成交按实际量计。
- **影响：**跨周、跳空成交与卖飞统计不同；允许 B 内旧单成交会直接违背暂停口径。
- **拍板：**总指挥定订单生命周期，qi 验证暂停期间零卖出。

## Q04 C 的解除条件

- **影响：**暂停时长、低位回补次数和未回补敞口不同。
- **拍板：**总指挥定恢复标准，qi 验证时间顺序。

## Q05 净收益门禁的预计买价与部分成交费用

- **问题/缺口：**任务只要求扣佣金/印花税/滑点后预计净收益达标，未定义未来买入报价的可观测估计及拆分卖佣的方法。
- **候选：**① 下单时可见报价作买入基价；② 回补区间内保守端点作预计报价；③ 可观测买一报价加预先登记缓冲。按已实现卖出现金流分摊时，可选按股数比例分摊已付费用或逐成交最小单位重算；两种会影响最低佣金处理。禁止事后用实际最低价反推门禁通过。
- **影响：**门禁通过率、成交前后净额差异及部分回补净额不同。
- **拍板：**总指挥定估计原则，qi 核对因果和逐笔费用。

## Q06 指标预热长度

## Q07 “均线走平/走弱”“放量/约 1.3 倍”的精确定义

- **问题/出入：**四状态口径采用定性词与“约”，原稿转述未给公式。状态 B 的量是周末当日量还是周量，20 日均量含不含当日，C 的放量是否沿用 1.3 倍，都未明确。
- **候选：**走平可用 MA20/MA60 的单日斜率绝对值容差或多日斜率；走弱可用两线同降或 MA20 下穿/低于 MA60；B 量可用确认周最后交易日量 ÷ 前 20 日平均量 ≥ 经批准的精确阈值，或周量与同长度周均量比较；C 放量可共用或独立阈值。每个容差/阈值须以开发段方案预先登记，不能在本稿把“约”擅改为精确 1.3。
- **影响：**A/B/C 命中、优先级冲突、预热和交易机会都变化。
- **拍板：**总指挥定语义/精确阈值，qi 确认计算与无前视。

## Q08 状态冲突优先级、保持及 D 恢复

- **问题/缺口：**总指挥给四状态行为，但没有规定同日 D/C/B/A 冲突的显示优先级、B 周条件在下周的有效期、D 退出条件。价格 >3.00 且 B 未满足时不属于 A。
- **候选：**安全候选 `D > C > B > A > NO_ACTION`，暂停动作合并生效；B 可仅周收确认后至下周确认前锁存，或每日用最近周收及当日日线重评；D 可在周收 ≥2.40 后退出，也可要求连续周确认。无状态匹配保持 NO_ACTION，若新增状态须单独批准。
- **影响：**同日买卖许可、状态时长、失效后恢复路径不同。
- **拍板：**总指挥定优先级/保持规则，qi 验证无歧义。

## Q09 价带触发与成交、第二回补带跨 C

- **问题/出入：**原稿只有价格区间；缺报价触发、挂单时效、跳空和 OHLC 同日穿越的成交模型。第二回补带 2.62–2.68 跨越 2.64，C 可能在区间内暂停回补。
- **候选：**① 收盘落带才发次日限价单，以次日可证实的价格成交；② 盘中触带且有可审计逐笔数据才成交；③ 日线 OHLC 触带但对买卖同日路径不明时保守判为未成交。C 成立时不回补；C 未成立而价格低于箱体时是否许可低档回补，须另定。
