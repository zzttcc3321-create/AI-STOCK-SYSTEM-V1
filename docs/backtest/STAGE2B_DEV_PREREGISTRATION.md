## 边界与计算口径

- 唯一研究窗口为 2023-10-09 至 2025-09-30（含）。载入器只从本地忽略目录的原始文件选择该窗口的 `candles`/`fields`，先按日期截断再解析、验证和计算；2025-10-01 起的行情与收益不得被研究逻辑读取、计算或报告。所有交易、分红、逐日权益及状态日志均以窗口末日为硬上限。
- 模式固定为 `development_research`，只启用第一、二批；第三、四批禁用。正式 `ready_for_stage2b=false` 和正式门槛 `null` 保持原样。机动仓归一为 `1.0`，每批 `0.25`。为逐笔复用 Stage 1 的人民币分取整、最低佣金和合法交易单位，采用**纯假设会计尺度**：`1.0 = 10,000` 研究单位，每批 2,500 研究单位；它不是实际持仓股数，所有报告仓位只写相对量。初始现金为 0，初始机动仓在窗口首日收盘按原始价标记，不构造买入交易。无核心仓与真实成本输入。
- 信号在完整日收盘后确认；周资格仅在完整周最后交易日北京时间 15:00 后更新。次日开盘先以已确认信号的价带及暂停/仓位/现金约束验单，再按原始开盘价加减本档滑点模拟成交；不回改前一日门禁。一次候选仅活到该开盘，失败即撤销。除息日按前收盘持有的研究单位在开盘成交前计公告含税现金，指标采用 Stage 1 的因果现金分红调整收盘价，成交、阈值和权益市值使用原始价。
- 卖出与回补均遵守 FIFO、T+1、单日不可反向回转、未回补成交前上限 `0.5`、现金和持仓非负。回补信号只在两档含端点价带内评价；预计每股净收益使用已付卖出费用按份额分摊、信号收盘估计买价及本档买入滑点/佣金，不含分红。D 审查触发后记待审风险；本研究无人工解除审查，恢复资格需审查风险已解除。

## 固定门槛候选网格

单位均为**预计已实现做 T 净收益，元/股**，在回补信号时使用。Stage 1 双边佣金各最低 5 元、卖出印花税 0.05%。按 2,500 研究单位和约 3.00 元卖价，最低佣金两边折合 `10/2500=0.004` 元/股，印花税约 `3.00×0.0005=0.0015` 元/股，往返费用约 `0.0055` 元/股，另有每边滑点。箱体宽 `3.00−2.64=0.36` 元，其四分之一为 `0.09` 元。下列网格覆盖低于费用、略高于费用、直到箱体四分之一；一经登记不增删改。

| 门槛 | 入选依据 |
| ---: | --- |
| 0.000 | 零净额底线，低于约 0.0055 元/股往返费用；检验仅要求费用后不亏的宽松候选。 |
| 0.004 | 与双边最低佣金折算相当，仍低于含印花税的约 0.0055 元/股。 |
| 0.010 | 高于典型往返费用，要求有小幅费用后净边际。 |
| 0.020 | 相当于基准滑点双边合计，用来观察滑点敏感性。 |
| 0.040 | 两档压力滑点双边合计，检验较明显的价差余量。 |
| 0.060 | 箱体宽度的六分之一，考察较严格筛选。 |
| 0.090 | 箱体宽度的四分之一，作为高门槛端点。 |

滑点固定为每股每边 `0 / 0.01 / 0.02` 元。费用及门禁对每档独立重算，不借用其他档的交易。

## 指标与事先固定的选择规则

每个门槛×滑点单独列出：卖出和回补成交数；已完成回补轮次（每个 FIFO 卖出腿对应的完整回补算一轮；若部分回补则另列完成相对量）；完成率=`已回补研究单位/累计卖出研究单位`，零卖出定义为 0；已实现做 T 净收益总额（研究尺度人民币）及每已回补单位净收益；期末未回补相对敞口；累计佣金、印花税和总费用；策略期末权益相对 Stage 1 首日收盘归一化买入持有基准（含税前现金分红、不再投资）的收益率差（百分点）；策略逐日权益最大回撤；实际收到的含税分红现金，与已实现净额分列；未回补卖出腿在持有缺口期间错过的含税现金分红备查，不计入做 T 净额。另列期末未回补腿按末日原始收盘的盯市额，不当作已实现收益。零交易如实记 0，并保留在比较表中，不放宽状态、价带或门禁制造交易。

建议门槛资格必须**同时**满足三档滑点各有至少一轮完整回补、各档已实现净额总额均 `>=0`，且各档完成率均 `>=50%`。在合格候选中，以三档的“已实现净额总额÷初始 10,000 研究单位”的中位数最高者为建议门槛；若同分，先取三档中最低完成率较高者，再取较低门槛。若无合格候选，明确报告“无建议门槛”，不临时降低标准。此规则只用于开发段比较，不自动写入正式执行器或改动 `ready_for_stage2b`。
